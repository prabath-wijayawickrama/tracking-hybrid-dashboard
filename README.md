# 📦 Hybrid Tracking → Warehouse Intelligence  
A browser‑based machine‑learning engine that predicts the correct warehouse (BER3 or POZ) from a tracking ID using a hybrid model:

- Prefix pattern learning  
- N‑gram similarity  
- Markov chain transitions  
- ML heuristic scoring  
- TensorFlow.js LSTM neural network  
- Combined hybrid confidence engine  

Everything runs **locally in the browser** — no backend, no server, no API.

---

## 🚀 Features

- Upload CSV (TrackingID, Merchant, Warehouse)
- Automatic training of all 5 intelligence layers
- Real‑time warehouse prediction
- Confidence score + visual bar
- Full model breakdown (prefix, n‑gram, markov, ML, LSTM)
- Merchant summary table
- Warehouse distribution summary
- Dark mode toggle
- Mobile view toggle
- 100% client‑side, works offline after load
